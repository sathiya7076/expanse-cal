# Smart Salary, Income & Expense Tracker (MERN)

- `backend/`  Express + MongoDB API with Tesseract.js receipt scanning. See `backend/README.md`.
- `frontend/` React + Vite + Tailwind CSS app. See `frontend/README.md`.

```bash
# terminal 1
cd backend && npm install && cp .env.example .env   # set MONGODB_URI and JWT_SECRET
npm run dev

# terminal 2
cd frontend && npm install && npm run dev            # http://localhost:5173
```
